# ZX-calculus Graduation Research

**研究テーマ：どのような回路にZX最適化が有効で、どのような回路では改善しないのか**

English working title: **Circuit-Dependent Effectiveness of ZX-Calculus-Based Quantum Circuit Optimization**

## 研究計画

**[研究計画と段階別ロードマップを開く](docs/research_plan.md)**

教授との相談に基づく2026年11月17日の改訂計画です。回路の種類・規模・構造による最適化効果の違いを主題とし、**Backward／Reverse抽出は主実験・副実験の両方から外します。** ZXは元の向きの標準抽出に固定し、方向の比較は行いません。以前の「30シード先行」「抽出戦略の自動選択モデル」「両方向比較」の計画より、この改訂計画を優先します。

| 段階 | 目的 | 作業の順序 | 主な成果物 |

| **第1段階：幅広い回路比較** | 有効例・無効例・トレードオフを探す | 仕様固定 → 入力準備 → 小規模な動作確認 → 33入力の比較 → 全体集計 → 対照例選択 → 次の仮説を固定 | 全入力比較表、ファミリー別集計、対照例候補 |

## 最初に比較する内容

初期案はQFT、Toffoli ladder、位相回路、反復Pauli回転回路、ランダムClifford＋Tの**5ファミリー・33入力**です。入力条件は実行前に固定します。

**[5種類の回路図と読み方](docs/circuit_diagrams.md)**：4量子ビットの図、構造の説明、英語のFigure caption、再生成用コードを掲載しています。位相回路と反復Pauli回転は説明用の例です。図の生成・数値確認は最適化のベンチマーク結果ではありません。

各入力について **Original／Gate-only／ZX** の3条件を比較し、主な基準はGate-onlyとします。ZXは `full_reduce` → 元の向きの標準抽出（`optimize_cnots=2`）→ 共通のゲート整理という固定手順です。T-count、2Q、depth、最適化時間、等価性を記録します。一般角を含むQFTは、Clifford＋T近似合成を行わない限りT-countをN/Aとし、主に2Q・depthを評価します。

主比較表は **33入力×3条件＝99行**です。ZX抽出は33入力につき1設定の33候補条件で、時間反復は別に数えます。独立した99回路を用意するという意味ではありません。

**直近の着手順：** 比較仕様と環境を固定し（S1-1）、入力一覧を作成し（S1-2）、各ファミリー1入力で3条件の検証と保存を確認してから（S1-3）、33入力を実行します（S1-4）。
