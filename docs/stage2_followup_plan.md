## 2. 全追試で固定する比較条件

比較は **Original / Gate-only / ZX** の3条件。基底、正規化、後処理、PyZX 0.10.8、検証器、時間範囲は [`stage1-standard-v1`](../runs/stage1-20261124T012423Z/protocol.json)を継承する。ZXは `full_reduce`、標準の元の向きの抽出、`optimize_cnots=2`, `optimize_czs=True`, `up_to_perm=False`、共通の `basic_optimization(do_swaps=False)` 1回に固定する。**Backward / Reverseは実施しない。**

- 量子ビット数は最大8。2Qは正規化後のCNOT＋CZ、depthは同じ論理層数の定義を使用する。
- Tは正規化後のT・T†の個数。QFTは一般角のまま扱い、T-countをN/Aとする。
- 全基底入力を用いる数値検証で、固定ワイヤ順、単位絶対値の大域位相のみ許容、`atol=1e-9, rtol=0`。raw→正規化→各出力を検証し、残差を保存する。これは有限精度の数値的証拠であり、厳密証明とは区別する。
- 各最適化手法にウォームアップ1回＋時間計測10回。手法順を交互にし、検証・保存・計数を最適化時間に含めない。Originalの最適化時間はN/A。
- 時間計測出力は検証済み出力とハッシュ一致を確認し、不一致ならその出力を検証する。元の60秒／処理・60秒／検証、2 GiB、BLAS 1スレッドの上限を継承する。
- 全失敗・タイムアウト・未判定を記録し、成功例だけへ差し替えない。新規定義は予定ID **`stage2-followup-v1`** の別生成器・マニフェストへ保存し、凍結した第1段階の生成器や結果を書き換えない。

判定は主にZX対Gate-onlyで行う。入力ごとに

\[
g_2=100\frac{N_{2Q,Gate}-N_{2Q,ZX}}{N_{2Q,Gate}},\qquad
S_2=N_{2Q,Gate}-N_{2Q,ZX}
\]

を報告し、正の値を削減とする。基準2Qが0なら百分率はN/A、絶対差を残す。T非増加かつ2Q減少を別途数え、depth・runtimeの増減も隠さない。下記の「8/10」は事前に決めた傾向の再現基準であり、統計的有意性や母集団全体への保証を意味しない。未検証の入力を成功として数えず、10件中の検証済み件数も併記する。

## 3. A：まず新入力で再現を確認する — 24入力・72行

| 対象 | 事前に固定した追加入力 | 入力数 | 仮説と、不支持とする条件 |
| --- | --- | ---: | --- |
| 位相回路の幅による対照 | n=4,8、80操作、各seed=100〜109 | 20 | H1：4qではT非増加・2Q減少が8/10以上かつg₂中央値>0、8qでは2Q増加が8/10以上かつg₂中央値<0。いずれかを満たさなければ、この強さの再現仮説は不支持 |
| Toffoli ladder | 現プロトコルでは未評価のサイズn=5,7、順にCCX(k,k+1→k+2) | 2 | H2：両サイズでT減少かつ2Q増加。どちらかでこの関係が崩れれば、探索で見えたトレードオフの単純な外挿は不支持 |
| QFT | 未使用サイズn=5,7、正のFourier位相、末尾SWAPあり | 2 | H3：両サイズで2Q・depthがともに増加。どちらかで一方が同等以下なら、この悪化傾向の単純な外挿は不支持 |
| **合計** |  | **24** | **3条件で72行。実行前の予定件数** |

位相回路は第1段階と同じ分布を用いる。1操作ごとに `random.Random(seed).random()` を引き、0.4未満なら `randrange(n)` で対象を決め、`choice([-3,-2,-1,1,2,3])×π/4` のZ位相を置く。それ以外は `sample(range(n),2)` の順序付き異なる2量子ビットへCNOTを置く。乱数の呼び出し順もこの順に固定し、偶然の重複を除去・選別しない。QFTとToffoliは[第1段階の定義](../benchmarks/broad_screening/circuits.py)を新しいnへ適用する。

予定IDは `stage2_phase_{n}q_L80_s{seed}`, `stage2_tof_ladder_{n}q`, `stage2_qft_{n}q`。seed 100〜109は今回の凍結済み探索入力0〜2と分離した確認用集合であり、結果に応じて都合のよいseedを追加しない。同じseedを異なるnで使っても同一のゲート配置にはならないため、幅の比較を「配置まで同じ回路の比較」とは解釈しない。

**Toffoliの5qは旧8回路パイロットに既出**である。今回はGate-onlyと共通後処理を加えた現プロトコルで再評価するが、完全に未知の確認用回路とは呼ばない。追試の「新しい入力ファイル数」は、新規な数学的回路や独立な未見標本の数を意味しない。

## 4. B：構造要因を切り分ける — 追加42入力・126行

以下の定義もAの結果を見る前に固定する。Aの仮説が不支持でも削除せず、その事実を受けて解釈する。

### B1. 幅と操作数：追加20入力

n=4,8、操作数L=80,160、seed=100〜109の**2×2×10=40入力**の配置を作る。L=80の20入力はAと同一なので、新しく作るのはL=160の20入力だけ。位相の分布・乱数呼び出し順はAを継承し、同じn・seedなら80操作の回路が160操作の先頭部分になる。予定IDは `stage2_phase_{n}q_L160_s{seed}`。

| 比較 | 揃えるもの | 検証する内容 |
| --- | --- | --- |
| 4q・80操作 ↔ 8q・80操作 | 総操作数80 | 第1段階の幅の対照を新seedで再確認 |
| 4q・80操作 ↔ 8q・160操作 | 操作数／量子ビット数=20（L=20n） | 固定80操作で見えた差が、この密度の揃え方でも残るか |
| 同じnの80操作 ↔ 160操作 | 幅・seed・最初の80操作 | 長さを増やしたときの変化 |
| 4q・160操作 ↔ 8q・160操作 | 総操作数160 | 80操作だけに依存した幅の傾向か |

H4は「8qにおける操作数増加が2Qの相対改善に寄与する」とする。seedごとの `g₂(8q,160)−g₂(8q,80)` が8/10以上で正、かつ中央値が正ならこの限定した予測を支持し、満たさなければ不支持とする。操作密度L/nは幅と長さから決まる量なので、これだけで抽象的な『密度だけの因果効果』を証明したとは言わない。位相の種類数、パリティ重複、CNOT接続も記録して代替説明を残す。

Aの決定的なゲート数結果は再利用する。異なる実行バッチ間の絶対runtimeを直接比較しない。版やパイプラインを変える必要が生じた場合は新プロトコルを作り、比較に必要な全条件を同じ設定で再測定する。

### B2. パリティ再利用：10組・20入力

6量子ビットで、3量子ビットのパリティに+π/4位相を付けるガジェットを8個並べる。支持集合 `a<b<c` の1ガジェットは時間順に `CNOT(a,c), CNOT(b,c), T(c), CNOT(b,c), CNOT(a,c)` と固定する。

各seed=100〜109で、`combinations(range(6),3)` の辞書順リストから `random.Random(seed).sample(...,8)` により異なる支持集合A〜Hを選ぶ。ペアの2入力を次のように作る。

- **再利用あり**：A, B, C, D, A, B, C, D。
- **再利用なし**：A, B, C, D, E, F, G, H。

両入力は正規化前後の入力T=8、2Q=32、6量子ビットを揃える。予定IDは `stage2_parity6_reuse_s{seed}` と `stage2_parity6_unique_s{seed}`。**両者は一般に異なるユニタリであり、同じアルゴリズムの二つの実装ではない。** 各入力を自身のOriginalに対して検証する。支持の出現頻度やdepthまで一致するとは仮定せず記録する。

H5は「重複パリティがZXのGate-onlyに対する追加利益に関係する」とする。ペアごとの `S₂(reuse)−S₂(unique)` が8/10以上で正、かつ中央値が正であることを2Qの支持条件とし、満たさなければ不支持。T-count差も全件報告し、Tを増やした改善はT非増加の成功例に含めない。

再利用側は同じ位相が加算されるように設計した**機構確認用の合成入力**である。ZXを使わない手法でもこの構造を利用できる可能性があるため、Original比の大きな削減だけをZXの追加効果としない。また、この人工的な冗長性で得た改善率を実用回路の改善率として扱わない。

### B3. Toffoliの重なり：2入力

6量子ビット、CCXを2個、同じ分解法で固定する。

| 予定ID | 時間順のCCX | 活性量子ビット数 |
| --- | --- | ---: |
| `stage2_tof6_disjoint2` | CCX(0,1→2), CCX(3,4→5) | 6 |
| `stage2_tof6_cascade2` | CCX(0,1→2), CCX(1,2→3) | 4（残り2本は恒等） |

両入力の正規化後T=14、2Q=12を揃える。H6は「連鎖側でZXの追加2Q負担 `N₂Q,ZX−N₂Q,Gate` が独立側より大きい」とする。差が0以下なら不支持。活性ワイヤ数も変わるため、これは重なりだけを完全に分離した証明ではない。連鎖側は探索済み4q ladderに恒等ワイヤを足した診断例であり、新しい独立アルゴリズムの確認例として数えない。2入力の表をそのまま示し、統計的有意性は主張しない。

## 5. C：処理過程を追って説明を作る

追加の回路群を広げず、A・Bの各条件から簡約前グラフ、簡約後グラフ、抽出直後の正規化回路、共通後処理後の回路を保存する。T・2Q・depthの増減がどこで生じたかを同じ入力内で追い、グラフ頂点数の減少だけで出力コストの改善を説明しない。

詳しく追跡する新入力は、結果に依存せず `stage2_phase_4q_L80_s100`, `stage2_phase_8q_L80_s100`, `stage2_tof_ladder_5q`, `stage2_qft_5q` と固定する。全件の最終表を残した上で、最初の2例とToffoliを主な3ケース、QFTを補足例とする。必要な抽出の行列操作やCNOT生成の記録は診断用の別実行に分け、測定runtimeへ混ぜない。
